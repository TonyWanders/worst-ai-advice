A program that writes one line of the worst possible advice an AI could
give to `/output/entry.txt`, for the make.fun competition
[Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 83 characters, inside the 1 to 140 gate.

## The entry

```
Certainly! If your smoke alarm keeps beeping, remove the battery. No beep, no fire.
```
